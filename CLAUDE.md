# Project rules

Unofficial browser port of Moto Racer Advance (GBA, 2002). See `docs/plan.md` for the phased plan and `docs/research/` for findings.

## Language

Everything in this repository is written in English: code, comments, docs, commit messages, PR descriptions, issues, and file names. This applies even when a conversation or source material is in another language: translate, don't copy.

## Legal hygiene

- Never commit the ROM, the GBA BIOS, saves, save states, assets extracted from the ROM, or code generated by recompiling the ROM. `.gitignore` covers the usual paths; keep it that way when adding new output directories.
- Never link to ROM download sites in docs or code.
- The app works from a ROM the player supplies. It is processed locally in the browser and never uploaded.
- gbarecomp is licensed PolyForm Noncommercial 1.0.0. Anything built on it stays noncommercial.

## Accuracy

- Facts about the game's internals (rendering mode, memory layout, function addresses, formats) go in `docs/research/` with how they were verified: tool used, ROM hash, address. Mark anything unconfirmed as **unverified**.
- Pin one ROM revision by hash and state it in every finding that depends on it.
