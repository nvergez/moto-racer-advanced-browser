# race_traffic.txt run to the finish: Traffic on Moscow, A held from frame
# 3600, START pauses at 4200 and resumes, then A stays held until the race is
# over. Fresh empty save; frame numbers as in ../../input/boot_to_race.txt.
# Used by run_ab.sh.
#
# With this script, on a retail-BIOS boot, the race display (DISPCNT 0x1741)
# runs from frame 3358 to 17468 (ab_report.py race_result; open-bios-ab.md
# section 4), and the mode-4 "Try again" screen (DISPCNT 0x1444) is up from
# 17493. Phase 1's 17909 for a Traffic race (phase1-findings.md section 2)
# does not apply here: race_traffic.txt ends at frame 6000, and what that run
# did after it is not recorded. The end also moves with the BIOS and the start
# (17560 for cult-skip), so the results overlay is not shot from this script
# at a fixed frame: run_ab.sh shoots it 60 frames before each run's own
# race-display end (ROUTE/result/shots/).

until 2450
tap START
wait 60
tap A                      # English -> main menu
wait 180
tap A                      # solo
wait 120
tap A                      # single race
wait 90
tap DOWN 2                 # cross -> traffic
wait 30
tap A                      # -> track select
wait 90
tap A                      # -> bike select
wait 90
tap A                      # -> gearbox
wait 90
tap A                      # Auto -> race loads
until 3600
hold A
until 4200
tap START                  # pause
wait 30
tap START                  # resume
wait 60
until 19000                # race over, "Try again" screen
mark after_race
shot after_race
end
